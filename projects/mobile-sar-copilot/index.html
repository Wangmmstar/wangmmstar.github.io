BIM defines where components belong. But how do workers find those locations on site?

Construction tasks are spread across different work areas. Workers must find the correct BIM target, mark its location on the physical surface, and check their work against the design.

The worker requests a task. The robot finds its BIM target.

“Mark the four drill holes for the AC bracket on the west wall.”

The co-pilot identifies the corresponding BIM target and retrieves its mounting pattern. If the request is ambiguous, it asks the worker to clarify.

The robot moves to the work area and projects the layout.

The mobile robot moves to the requested work area. Using the site map and local wall references, it aligns the projection with the physical wall and displays the mounting pattern at full scale.

The worker marks the wall. The robot checks the result.

With the projection still on, the co-pilot compares the worker's marks with the original target. It flags shifted or missing marks and requests another view when the evidence is unclear.

Each check remains linked to the BIM target. Final acceptance remains with a human supervisor.

Could one robot coordinate installation tasks across an entire jobsite?

Today, the co-pilot guides and checks individual installation targets. The next challenge is coordinating many BIM-defined tasks across different work areas—keeping track of where each task belongs, what has been completed, and what still needs attention.
