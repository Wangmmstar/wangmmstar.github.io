Robotic targets are still robot-specific.

BIM can define where a construction component should be installed. For robotic execution, that target is typically transformed into an absolute pose for a particular robot and workcell.

This works—but the project-specific target must be re-expressed for each execution system.

Robot-specific target delivery
Workface spatial interface

Put the target at the workface.

Instead of bringing the project target into each robot’s coordinate representation, we materialize it directly at the physical workface as an observable spatial reference.

The workface becomes the interface between design intent and execution.

From BIM target to workface reference

The BIM-defined installation target is converted into a projection-ready spatial cue and materialized at the point of work.

How the BIM-to-workface interface is built →

Align to what you see, not to a BIM pose.

The robot observes the held component and the projected target locally and generates incremental corrective motion.

The controller does not receive the BIM-defined installation target as an absolute robot-frame goal.

A target that lives at the workface.

The contribution is not simply a robot that follows a projected contour. It is a different way to deliver project-specific design intent to execution.

By externalizing the target at the workface, project-specific target definition can remain separate from robot-specific perception and control.
