Overview

This work combines a custom laser projection platform with a BIM-to-workface pipeline to materialize selected installation targets as full-scale spatial references where construction work happens.

The design is digital. The work is physical.

BIM may already define what should be installed and where it belongs. At the workface, however, that information still has to be interpreted, located, measured, and marked before installation can begin.

A tablet changes how the design is displayed, but it does not remove the spatial translation between the digital model and the physical place where the work happens.

The worker no longer has to reconstruct the target on the workface from a separate representation.

From digital design to the physical workface.

A selected BIM object is converted into a projection-ready laser pattern and reproduced at full scale on the physical workface.

A physical interface for digital design.

Moving design intent to the workface requires more than a digital representation. We designed and built a compact laser projection platform that reproduces vector geometry directly on physical surfaces. An integrated camera supports spatial registration between the projection unit and the workface.

Move the translation upstream.

Conventional layout repeats the same spatial translation at execution time: understand the design, locate the physical surface, transfer dimensions, measure, and mark.

We instead prepare a workface-referenced installation target before field execution. A user selects the BIM object, and its geometry, pose, and supporting workface are prepared as a reusable target pattern. During field execution, the system registers the physical workface and retrieves the corresponding target.

Prepare the spatial target once. Reuse it where the work happens.

If projection replaces layout, it must preserve layout accuracy.

Physical layout exists to establish where work should happen. A projected reference is only useful if it can preserve that spatial relationship.

We therefore evaluated the projection system itself, including center-position accuracy and shape stability across projection distances and target geometries.

One projection interface, different carriers.

The evaluated prototype used a tripod-mounted, marker-localized configuration. The projection unit itself is a separable module, leaving room for future integration with other positioning platforms.

Evaluated setup

Tripod-mounted projection system with camera/marker-based workface localization.

Potential deployment

The same projection interface can be integrated with other positioning carriers, such as a robotic platform.

Beyond simple geometry.

The workflow was demonstrated across geometric targets, BIM-derived building components, and manufacturing assembly patterns.

From digital intent to physical action.

This work establishes a physical design-to-workface interface: selected installation intent is prepared digitally and materialized as a spatial reference at the place of execution.

Once the target exists on the workface, the next question is who—or what—can act on it.
